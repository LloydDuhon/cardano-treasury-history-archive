# Code Of Conduct

This repository welcomes community contributions to improve the accuracy,
provenance, and usability of Cardano treasury history data.

## Expected Behavior

- Be respectful and specific.
- Critique records, sources, methods, and code; do not attack people.
- Provide evidence for data claims.
- Assume confidence labels matter. If evidence is incomplete, say so.
- Keep security reports private by following `SECURITY.md`.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private personal information.
- Repeatedly asserting data corrections without evidence.
- Using issues or pull requests to promote unrelated projects or proposals.
- Publicly posting exploit details before a security issue has been triaged.

## Enforcement

The maintainer may edit, close, lock, or remove contributions that violate this
code of conduct. Serious or repeated violations may result in a block from the
repository.
