# Support

This project has two separate support paths: public data/methodology support and
private security reporting.

## Data Questions And Methodology Support

Use GitHub issues for:

- Questions about report methodology, confidence labels, or source coverage.
- Suspected data errors.
- Proposed new sources.
- Local ETL or static-site usage problems.
- Requests for clarification on a proposal, proposer, or funding record.

Please include the affected proposal id, report filename, source URL, or command
output whenever possible. Data corrections should cite primary sources.

## Security Reports

Do not use public issues for vulnerabilities. Follow `SECURITY.md` for private
security reporting.

Security reports include site XSS, credential exposure, poisoned data artifacts,
unsafe GitHub Actions behavior, and other issues that could compromise users or
the integrity of the published archive.
